# ADR 0004: Export Pipeline

## Status

Accepted

## Context

Bonda needs deterministic visual exports while remaining offline-first and preserving privacy.

## Decision

- Poster and stats exports are created from captured React Native views.
- iOS advanced exports are generated by a native module:
  - PDF export renders a branded document from the captured image and summary payload.
  - Loop export renders a short branded video from a single captured frame.
- Android currently exposes the shared poster/stats export path and rejects advanced exports until native parity is implemented.

## Consequences

- Export generation remains local and deterministic.
- iOS can ship richer outputs without introducing remote dependencies.
- Android behavior is explicit rather than silently failing.
